Dashboard di Monitoraggio Sistema 

Uno script interattivo da riga di comando per monitorare in tempo reale lo stato di salute del sistema operativo tramite un menu testuale guidato.

🚀 Caratteristiche Tecniche

Cicli Infiniti Controllati (while true + clear): Mantiene il menu attivo e pulisce lo schermo ad ogni interazione.

Gestione delle Scelte (case): Instrada in modo efficiente l'input dell'utente verso i comandi di sistema appropriati.

Comandi Nativi Ottimizzati: Sfrutta tool nativi formattati per una lettura rapida (df -h, free -h, uptime).
